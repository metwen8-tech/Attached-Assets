# WEND 3D — PASSAGE DE PROTOTYPE À APPLICATION FONCTIONNELLE

Tu travailles sur le projet **WEND 3D — METELLUS OS** déjà créé.

NE REFAIS PAS LE DESIGN DEPUIS ZÉRO.

Conserve l'identité visuelle, la scène 3D, l'orb WEND, les animations et la structure existante.

Ta mission est maintenant de transformer le prototype en une **application réellement fonctionnelle et interactive**.

---

# 1. RÈGLE PRINCIPALE

Chaque bouton visible doit faire quelque chose.

Chaque menu doit fonctionner.

Chaque fenêtre doit fonctionner.

Chaque paramètre doit être sauvegardé.

Aucune interaction importante ne doit être une simple animation sans logique derrière.

Avant de modifier quoi que ce soit :

1. analyse le projet existant ;
2. identifie les composants déjà créés ;
3. identifie les fonctionnalités déjà fonctionnelles ;
4. conserve-les ;
5. améliore uniquement ce qui manque.

Ne casse jamais une fonctionnalité existante.

* interactions UI
* stockage local
* raccourcis clavier
* fullscreen
* reconnaissance vocale si disponible
* animations
* navigation
* gestion des fenêtres

### SIMULÉ

* CPU
* RAM
* réseau
* stockage système
* scan système
* fichiers Windows
* agents IA

Ne jamais présenter une donnée simulée comme une vraie donnée système.
